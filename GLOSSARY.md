# Calendar

Приложение для записи на звонки: гости выбирают свободный слот и записываются, владелец видит предстоящие события.

## Language

**Meeting type** (Тип встречи):
Предложение владельца для записи на звонок с названием, описанием и длительностью.

**Booking** (Запись):
Выбранное гостем время и контактные данные для будущего звонка.
_Avoid_: бронирование, appointment

**Booking attempt** (Попытка записи):
Намерение гостя создать одну запись с выбранным слотом и контактными данными; его результат может быть подтверждён, отклонён или неизвестен.

**Slot** (Слот):
Интервал, доступный для записи, длительность которого определяется типом встречи.
_Avoid_: время, интервал

**Upcoming events** (Предстоящие события):
Список записей, время начала которых ещё не наступило.
_Avoid_: расписание, календарь владельца
