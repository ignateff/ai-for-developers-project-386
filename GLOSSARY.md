# Calendar

Приложение для записи на звонки: гости выбирают свободный слот и записываются, владелец видит предстоящие события.

## Language

**Booking** (Запись):
Выбранное гостем время и контактные данные для будущего звонка.
_Avoid_: бронирование, appointment

**Slot** (Слот):
Конкретный 30-минутный интервал, доступный для записи.
_Avoid_: время, интервал

**Upcoming events** (Предстоящие события):
Актуальный список записей с датой в будущем.
_Avoid_: расписание, календарь владельца
