# Дизайн

## Источник правды

**Основной файл дизайна:** [`calendar-booking.pen`](./calendar-booking.pen) — дизайн-макет в формате Penpot JSON.  
**Роль:** единственный источник для визуальных спецификаций (цвета, типографика, размеры, layout, состояния компонентов).

**Функциональные требования** живут в связанных GitHub Issues. При расхождении между дизайном и согласованной спецификацией — правила берутся из Issue, а не из макета. Любое неоднозначное расхождение требует уточнения у оператора.

---

## Проверка реализации

Для каждого затронутого экрана и состояния прочитайте соответствующий фрейм `.pen` и сравните его с работающим приложением в браузере при сопоставимом размере окна. Проверьте композицию, размеры, отступы, типографику, цвета и состояния компонентов; отдельно проверьте узкий экран, загрузку, пустые состояния и ошибки. Для состояний без готового фрейма придерживайтесь дизайн-системы и функциональной спецификации.

Зафиксируйте проверенные экраны и размеры окна, исправьте обнаруженные расхождения и повторите сверку до завершения UI-задачи. Если какая-либо проверка невозможна, сообщите об этом и о непроверенных состояниях. Утверждённые эталоны визуальных регрессионных тестов и требования к их стабильности описаны в `docs/agents/testing.md`.

## Как читать макет

Файл `calendar-booking.pen` — это JSON. Корневой массив `children` содержит фреймы (экраны). Каждый фрейм имеет поля:

- `name` — название экрана
- `width`, `height` — размеры холста
- `fill` — фоновый цвет
- `children` — вложенные элементы (текст, иконки, фреймы)

Элементы описываются полями: `type`, `x`, `y`, `width`, `height`, `fill`, `fontFamily`, `fontSize`, `fontWeight`, `content`, `cornerRadius`, `stroke`, `strokeWidth`.

## Дизайн-система (светлая тема)

### Цвета

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--bg-page` | `#F5FAF8` | Фон страницы |
| `--bg-surface` | `#FFFFFF` | Фон карточек, панелей |
| `--bg-header` | `#FFFFFF` | Верхняя панель |
| `--bg-inactive` | `#F2F5F8` | Неактивные/прошедшие дни, занятые слоты |
| `--bg-selected` | `#E4F6F2` | Выделенный день, выбранный слот |
| `--bg-active-tab` | `#E5F2EE` | Фон активного пункта навигации |
| `--text-primary` | `#102039` | Основной текст, заголовки |
| `--text-secondary` | `#617994` | Подписи, подзаголовки, легенды |
| `--text-tertiary` | `#90A3B8` | Неактивные дни, статус «занято» |
| `--accent` | `#087F7A` | Акцентный цвет: кнопки, выделения, иконки |
| `--border` | `#D9E2EC` | Рамки карточек, слотов |
| `--border-light` | `#E8EEF4` | Рамки неактивных элементов |

### Типографика

| Элемент | Font | Size | Weight | Color |
| --- | --- | --- | --- | --- |
| Заголовок страницы | Inter | 28px | 700 | `--text-primary` |
| Подзаголовок | Inter | 15px | 400 | `--text-secondary` |
| Заголовок карточки | Inter | 18px | 700 | `--text-primary` |
| Значение поля | Inter | 14px | 600 | `--text-primary` |
| Подпись поля | Inter | 13px | 400 | `--text-secondary` |
| Навигация | Inter | 14px | 500/400 | `--text-primary` / `--text-secondary` |
| День недели | Inter | 12px | 600 | `--text-secondary` |
| Число дня | Inter | 14px | 400/700 | `--text-tertiary` / `--text-primary` |
| Доступность | Inter | 10px | 400 | `--accent` / `--text-secondary` |
| Время слота | Inter | 13px | 700/500 | `--text-primary` / `--text-tertiary` |
| Статус слота | Inter | 11px | 400 | `--text-tertiary` |

### Скругления

| Элемент | Radius |
| --- | --- |
| Карточки (панели) | 14px |
| Внутренние блоки информации | 10px |
| Кнопки, иконки, ячейки календаря | 8px |

### Иконки

Библиотека: **Lucide** (`library: "lucide"`). Используемые иконки:

- `calendar-clock` — логотип в шапке
- `chevron-left` / `chevron-right` — навигация по месяцам
- `clock-3` — часовой пояс
- `check` — отметка выбранного слота

## Компоненты

### Верхняя панель (Header)
- Высота: 64px, фон `#FFFFFF`, нижняя рамка `#E2E8F0` 1px
- Слева: иконка `calendar-clock` (20×20, `#087F7A`) + текст «Calendar» (Inter, 16px, bold, `#102039`)
- Справа: навигация «Записаться» (активный пункт: фон `#E5F2EE`, радиус 8px) и «Предстоящие события»

### Карточка «Информация о записи`
- Размер: 268×580px, фон `#FFFFFF`, рамка `#D9E2EC`, радиус 14px
- Заголовок «Информация» + подзаголовок «Ваш выбор»
- Блоки-пары «подпись → значение» с фоном `#EDF5F2`, радиус 10px
- Поля: Выбранная дата, Выбранное время, Свободно (количество слотов), Длительность
- Внизу: иконка `clock-3` + часовой пояс (Москва, UTC+3)

### Карточка «Календарь»
- Размер: 435×580px, фон `#FFFFFF`, рамка `#D9E2EC`, радиус 14px
- Заголовок «Календарь», подсказка «Выберите день»
- Навигация по месяцу: название месяца + стрелки `chevron-left`/`chevron-right` в квадратах 36×36px
- Заголовки дней недели (Пн–Вс): 12px, `#617994`
- Ячейки дней: 50×50px, радиус 8px
  - Прошедшие/неактивные: фон `#F2F5F8`, текст `#90A3B8`
  - Доступные: фон `#FFFFFF`, рамка `#D9E2EC`, текст `#102039`, подпись с количеством слотов (10px, `#617994`)
  - Выбранный: фон `#E4F6F2`, рамка `#087F7A`, текст `#102039` bold, подпись `#087F7A`
- Легенда внизу: «Доступные дни отмечены количеством слотов»

### Карточка «Доступное время»
- Размер: 369×580px, фон `#FFFFFF`, рамка `#D9E2EC`, радиус 14px
- Заголовок «Доступное время», подзаголовок: «День, дата · длительность»
- Слоты в сетке 2 колонки: 157×36px, радиус 8px
  - Свободный: фон `#FFFFFF`, рамка `#D9E2EC`, время bold `#102039`
  - Занятый: фон `#F2F5F8`, рамка `#E8EEF4`, время `#94A6B7`, статус «Занято» `#90A3B8`
  - Выбранный: фон `#E4F6F2`, рамка `#087F7A`, время bold `#102039`, галочка `check` `#087F7A`
- Кнопки внизу: «Назад» (обводка) и «Продолжить» (заливка `#087F7A`, белый текст)

### Форма подтверждения
- Аналогичная карточка справа вместо календари+слотов
- Заголовок «Подтверждение записи», кнопка «Изменить» (возврат к выбору слота)
- Поля ввода: Имя, Email — рамка `#D9E2EC`, радиус 8px
- Кнопка «Подтвердить запись» — заливка `#087F7A`, белый текст, полная ширина
- Слева сохраняется карточка «Информация о записи»

### Успешное состояние
- Заголовок «Бронь подтверждена. До встречи!»
- Кнопка «Забронировать ещё» — заливка `#087F7A`

### Список предстоящих событий
- Карточки записей: фон `#FFFFFF`, рамка `#D9E2EC`, радиус 14px
- Поля внутри: имя гостя (bold), email (secondary), слот UTC, время создания
