# Скриншоты дизайна

**Роль:** визуальные ориентиры для реализации интерфейса.  
**Источник требований:** связанные GitHub Issues — при расхождениях между скриншотом и согласованной спецификацией правила берутся из Issue, а не из скриншота. Любое неоднозначное расхождение требует уточнения у оператора.

## Примечания

- Все контактные данные на скриншотах — искусственные демо-данные (`example.com`, timestamp-имена).
- Снимки отражают текущую версию макета и могут содержать интерфейсные детали, не описанные в спецификациях — такие детали не являются требованиями без отдельного согласования.
